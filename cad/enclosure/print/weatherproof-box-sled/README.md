## Print this one for the field unit

`sled-1554h-walter-rev1.stl` (or `.3mf`): carrier for the Walter board inside the Hammond 1554H2GY
box. Print 1, flat, in PETG or ASA, no supports. It also needs 4 toe clamps: use
`toe-clamp-rev1.stl` from `print\bench-case-devkitc\`. Assembly, what to solder and what is
unverified: the `README.md` in `cad\enclosure\` (two folders up).

## Kept for reference, not needed now

`sled-1554h-fnk0091-rev1.*` and `sled-1554h-fnk0101-rev1.*` carry the Freenove and DevKitC
boards on their breakouts in the same box. The field unit uses a Walter board, so these two are
not needed yet and are not archived.
