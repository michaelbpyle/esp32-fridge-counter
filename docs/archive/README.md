# Archive

Files kept for the record. They describe plans that were replaced on 2026-11-14, when the
direction became "WiFi now, LTE later".

- `build-out-tutorial.md`: the first build plan and the comparison of nine ways to send the
  data (Google Sheets, Meshtastic, cellular and others). Its Walter research (Option 9) is
  still accurate.
- `SWAMPNET-BRIEF.md` and `SWAMPNET-EMAIL.md`: the brief and draft email for the SwampNet
  mesh partnership. The email was never sent.

Older entries in `project-log.md` mention these files by their previous location at the top
of the project.
