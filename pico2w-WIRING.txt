FRIDGE DOOR COUNTER - WIRING REFERENCE (Pico 2W)
=================================================

COMPONENTS:
  - Raspberry Pi Pico 2W
  - Reed switch (normally open, 2 wires)
  - Magnet (for reed switch)


CONNECTIONS:
============

  Reed Switch Wire 1  →  GND (pin 38, or any GND pin)
  Reed Switch Wire 2  →  GP15 (pin 20)

  Note: Reed switch has no polarity - wires are interchangeable


PICO 2W PINOUT (USB port facing UP):
====================================

              ┌─────────────────┐
              │    [USB-C]      │
              ├─────────────────┤
     GP0   1  │●               ●│ 40  VBUS
     GP1   2  │●               ●│ 39  VSYS
     GND   3  │●               ●│ 38  GND  ←── Reed switch wire 1
     GP2   4  │●               ●│ 37  3V3_EN
     GP3   5  │●               ●│ 36  3V3(OUT)
     GP4   6  │●               ●│ 35  ADC_VREF
     GP5   7  │●               ●│ 34  GP28 (ADC2)
     GND   8  │●               ●│ 33  GND
     GP6   9  │●               ●│ 32  GP27 (ADC1)
     GP7  10  │●               ●│ 31  GP26 (ADC0)
     GP8  11  │●               ●│ 30  RUN
     GP9  12  │●               ●│ 29  GP22
     GND  13  │●               ●│ 28  GND
    GP10  14  │●               ●│ 27  GP21
    GP11  15  │●               ●│ 26  GP20
    GP12  16  │●               ●│ 25  GP19
    GP13  17  │●               ●│ 24  GP18
     GND  18  │●               ●│ 23  GND
    GP14  19  │●               ●│ 22  GP17
    GP15  20  │●               ●│ 21  GP16
              └─────────────────┘    ←── Reed switch wire 2 (GP15, pin 20)

    Note: Pico 2W has WiFi LED on the CYW43 chip, not a GPIO pin.
          The arduino-pico core handles this via LED_BUILTIN.


PHYSICAL INSTALLATION:
======================

    FRIDGE DOOR                    FRIDGE FRAME
    ───────────                    ────────────

    ┌─────────┐                    ┌─────────────────────┐
    │         │                    │                     │
    │ [MAGNET]│◄── ~1-2cm gap ──► │[REED SWITCH]        │
    │         │                    │      │              │
    │         │                    │      │ wires        │
    └─────────┘                    │      ▼              │
                                   │  ┌────────────┐     │
                                   │  │  Pico 2W   │     │
                                   │  │ (in case)  │     │
                                   │  └────────────┘     │
                                   └─────────────────────┘

    - Mount MAGNET on the door (the moving part)
    - Mount REED SWITCH on the frame (the stationary part)
    - Keep gap under 2cm for reliable triggering
    - Test alignment before permanent mounting


HOW IT WORKS:
=============

    Door CLOSED:  Magnet near → Reed switch CLOSED → GP15 reads LOW
    Door OPEN:    Magnet away → Reed switch OPEN → GP15 reads HIGH (internal pullup)

    The code detects the LOW→HIGH transition and increments the counter.


TROUBLESHOOTING:
================

    Problem: No detection
    → Check wiring connections
    → Test reed switch with multimeter (continuity mode)
    → Make sure magnet is close enough

    Problem: Double counting
    → Increase DEBOUNCE_MS in config.h (try 300 or 500)
    → Door may be bouncing - check hinges

    Problem: Missing counts
    → Decrease DEBOUNCE_MS in config.h (try 100)
    → Magnet may be too far from switch

    Problem: WiFi not connecting
    → Verify SSID and password in config.h
    → Ensure 2.4GHz network (Pico 2W doesn't support 5GHz)
